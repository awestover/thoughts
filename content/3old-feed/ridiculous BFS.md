Let $n$ be the number of vertices in the graph. Let $D$ be a bound on the diameter. The sequence length will be $n+1$. One token for each vertex, and then one special token to output the answer.
We won't need positional encodings. 

Let $a_{i}[v]$ denote the layer $i$ activations for the token $v$'s "deep embedding". $a_i[v]$ will live in $\mathbb{R}^{2n+1+D}$. The first coordinate of $a_i[v]$ will be an indicator for whether $i$ is the answer token. (1=answer token, 0 else). The next $n$ coordinates of $a_i[v]$ will be indicators for whether $v$ has a neighbor to each vertex $w$ (listed in order). The next $n$ coordinates of $a_i[v]$ will be indicators (ok they won't quite be 0/1 valued, but will be close to it) for whether $v$ can reach all the other vertices. 
The last $D$ coordinates will be zero. 
Now, for $a_i[ANS]$ we put all ones in the NBR / REACH slots and then in the final $D$ coordinates we start them out as zero they will store whether 1 can reach 2 in that number of steps. 

We will have $D$ layers and $n$ heads per layer.
The Key/Query/Value matrices will be computed as follows:
$\mathsf{key}_u(v) =  [0,0]$  or $[1000,0]$  based on whether $v$ can reach $u$. 
$\mathsf{query}_u(v) = [0,1]$ or $[1,1]$ based on whether $u$ is a neighbor of $v$.
$\mathsf{query}_u(\mathsf{ANS}) = [0,50]$
$\mathsf{key}_u(\mathsf{ANS})= [0,0]$.

Now compute the scores, and softmax it. 

Now, concatenate the heads and feed them through the following MLP:

- subtract $.5$

- position it correctly

now this output gets added to the residual stream for that token

def SSSP(G):
    dist = [MAXDIST for _ in G]
    dist[SOURCE] = 0
    frontier = deque()
    frontier.append(SOURCE)
    while len(frontier) > 0:
        vtx = frontier.popleft()
        for x in G[vtx]:
            if dist[x] == MAXDIST:
                dist[x] = 1 + dist[vtx]
                frontier.append(x)
                if x == TARGET:
                    return dist[TARGET]
    return MAXDIST
